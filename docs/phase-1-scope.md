# Phase 1 Scope

Included:

- Monorepo structure and workspace scripts
- TypeScript frontend and backend
- Express JSON API, CORS, logging, and error middleware
- MongoDB and Redis connection foundations
- CandidateProfile, Job, and Application schemas
- Admin-only JWT authentication
- API and system health endpoints
- Shared TypeScript contracts
- Login and protected dashboard shell
- Environment examples and local setup documentation

Deferred to later phases:

- Job source integrations and scraping
- Cross-source deduplication, freshness, and matching
- LLM analysis and resume tailoring
- Browser automation and job-site credentials
- Application submission workflow
- Notifications, analytics, deployment, and production monitoring
